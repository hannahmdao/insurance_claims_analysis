# Insurance Claims Frequency & Severity Analysis

## Overview

This project analyzes automobile insurance claims using R to investigate claim frequency,
severity, and expected loss costs.

The analysis applies actuarial and statistical modeling techniques to identifty factors associated 
with insurance risk and estimate expected claims costs. 

## Objectives 

- Analyze insurance claim frequency and severity
- Explore relationships between policy holder, vehicle characteristics, and claims
- Develop statistical models for claim frequency
- Develop statistical models for claim severity
- Evaluate model performance
- Combine frequency and severity estimates to calculate expected loss costs.

## Methodology

This project will investigate:

- Exploratory Data Analysis
- Generalized Linear Models (GLMs)
- Poisson regression 
- Negative Binomial regression
- Gamme regression
- Model diagnostics and validation 
- Pure premium estimation
